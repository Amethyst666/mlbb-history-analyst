# MLBB Analyst (Аналитик MLBB)

[English Version](README.md) | **Русская версия**

Продвинутый парсер истории матчей и трекер статистики для Mobile Legends: Bang Bang.

> [!WARNING]
> **Предупреждение о патчах и обновлениях игры:**
> После выходов очередных патчей и обновлений Mobile Legends структуру бинарных файлов историй боев (`FightHistory`) может измениться. В связи с этим в приложении могут временно возникать ошибки при распознавании, парсинге или определении различных элементов статистики (героев, предметов, оценок и параметров матчей) до момента выпуска соответствующего обновления парсера.

## Возможности

- **Парсинг истории матчей:** Прямое чтение бинарных файлов матчей (`FightHistory`) из директории игры. Поддерживает режимы 5v5 (Обычный и Ранговый) и автоматически отфильтровывает сторонние режимы.
- **Подробная статистика:** Расчет KDA, золота, урона (нанесенный, полученный, урон по башням), исцеления и длительности контроля за каждый матч.
- **Статистика по линиям и ролям:** Сортировка по линиям (EXP, Mid, Roam, Jungle, Gold) с локализованными именами, диаграммами и детальной аналитикой.
- **Союзники и профили игроков:** Отслеживание синергии с тиммейтами, винрейта, совместных игр, управление алиасами (псевдонимами) и заметками.
- **Фильтрация соло-игр:** Возможность переключения отображения всей статистики только по соло-матчам в настройках.
- **Обслуживание базы данных:** Очистка поврежденных или не-5v5 матчей в один клик.
- **Галерея ресурсов:** Просмотр данных о героях, предметах и заклинаниях.
- **Мультиязычность:** Полная поддержка русского и английского языков.
- **Современный интерфейс:** Темная тема и адаптивный дизайн.

## Установка и настройка

### Доступ к истории матчей (Android 11+)

Из-за ограничений Scoped Storage в Android для доступа к папке `Android/data` требуются специальные разрешения. Приложение поддерживает два метода:

#### 1. SAF (Storage Access Framework) — Рекомендуемый
Официальный метод Android, требующий однократного выбора папки вручную.

1. Перейдите в **Настройки** -> **Метод доступа к файлам**.
2. Выберите **SAF (Системный выбор)**.
3. Нажмите **Настроить доступ SAF**.
4. Перейдите в папку `Android > data > com.mobile.legends > files > dragon2017 > FightHistory`.
   * *Для версии из AppGallery путь: `com.mobilelegends.hwag`*.
5. Нажмите кнопку **"Использовать эту папку"** внизу экрана и подтвердите доступ.

*Примечание: На некоторых прошивках (Xiaomi, Samsung Android 13/14) системный проводник может блокировать выбор `Android/data`. В этом случае используйте метод Shizuku.*

#### 2. Shizuku (Продвинутый)
Использует разрешения ADB для прямого доступа к файлам игры в обход ограничений системного проводника.

1. Установите приложение **Shizuku** (из Google Play или GitHub).
2. Запустите сервис Shizuku (через отладку по Wi-Fi или Root).
3. В **MLBB Analyst** перейдите в **Настройки**.
4. Выберите **Shizuku (ADB)** в качестве метода доступа.
5. Нажмите **Проверить статус Shizuku** и разрешите доступ в системном окне.

## Использование

1. Откройте приложение.
2. Нажмите кнопку **+** (или включите Авто-импорт в настройках) для загрузки последних матчей 5v5.
3. Просматривайте детализацию матчей, статистику героев, показатели линий и профили игроков.

## Разработка

Проект разработан на Flutter.

```bash
flutter pub get
flutter run
```

### Зависимости
- `sqflite`: Локальное хранилище SQLite.
- `shared_preferences`: Сохранение пользовательских настроек.
- `permission_handler`: Управление разрешениями.
- `file_picker`: Выбор файлов.
